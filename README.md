# 希翎 ZU27DR 星座图上位机

本仓库保存 ZU27DR FPGA 板卡的 MATLAB 上位机程序，用于实时显示星座图和链路指标，并记录逐包指标与全部 I/Q 星座点。仓库不包含 FPGA 逻辑或固件。

## 文件

- `WPR_Metrics_GUI.m`：推荐的单文件入口，显示星座图、EVM、PER、BER 估算值、MER 和 Rx IF Power，并保存完整采集记录。
- `WPR_GUI.m`、`WPR_GUI.fig`：旧版 GUIDE 界面，仍可独立运行；它的星座点记录与新程序分开。
- `proc_udp1.m`：UDP 数据接收、界面更新、星座点记录。
- `Handshaking.json`、`Constellation.json`：握手和星座数据请求。
- `int2asc2.m`、`parse_json.m`：通信帧辅助函数。
- `Log_UESTC.jpg`：主界面使用的图片资源。
- `tests/test_WPR_Metrics_GUI.m`：三种调制的离线回归测试。

## 运行

需要 MATLAB R2023b、Communications Toolbox 和支持旧版 UDP `udp` 对象接口的 Instrument Control Toolbox。将 MATLAB 当前文件夹切换到本仓库目录，在命令窗口运行推荐入口：

```matlab
WPR_Metrics_GUI
```

界面顶部的 `Board IP` 用于输入板卡地址，端口固定为 `5001`。首次启动默认 `192.168.0.27`；点击 `Apply IP` 后，地址保存在当前电脑的 MATLAB 偏好设置中，下次启动会自动恢复。偏好设置按电脑本地保存，不会同步进 Git；另一台电脑可以独立使用 `192.168.0.28`。

左上角可单选 `QPSK`、`8PSK` 或 `16QAM`，每次重新打开界面默认 QPSK。选择后会更新红色参考点、星座图标题及 EVM/MER 的计算依据，并清空上一轮的屏幕数据。板卡调制仍按原有方式设置，采集前应让 GUI 选择与板卡实际调制一致。

确认 IP 和调制后点 `START` 开始请求和记录，点 `STOP` 停止并保存。从开始到保存完成，调制选择、IP 控件和 `START` 都会锁定；保存成功或失败后恢复操作。一次采集固定使用一种调制，切换调制前先停止保存。图表保留最近 50 个数据包用于实时观察，记录文件不设固定点数上限。

三种模式的参考星座均为单位平均功率，软件默认参数如下：

| 调制 | 参考星座 | 相位约定 |
| --- | --- | --- |
| QPSK | 沿用原 QAM-4 四点参考，I/Q 均为 `±1/sqrt(2)` | 四点位于 45°、135°、225°、315° |
| 8PSK | 单位圆上等间隔八点 | 默认偏置 22.5°，相邻点间隔 45° |
| 16QAM | 标准方形十六点，I/Q 电平为 `[-3,-1,1,3]/sqrt(10)` | 方形星座不额外旋转 |

三种模式统一沿用 `I/Q / (150 * sqrt(2))` 换算，原始点完整保留，不做逐包幅度或相位拟合。切换调制及每次 `START` 都重新创建 EVM/MER 计算对象，各包按当前参考星座计算指标。上述幅度和相位是软件默认值，须经实板参考点重合检查后，才能确认 EVM/MER 的测量有效性。

BER 按 `108000` bit 包长从 PER 推算，界面和记录均标为估算值；板卡返回的 `rms` 保留标注为 `Rx IF Power`，不将其解释为 RSSI。

旧版 GUIDE 程序仍可按原方式运行：

```matlab
WPR_GUI
```

## 采集文件

停止记录后，程序在 `constellation_records/constellation_年月日_时分秒/` 下保存：

- `metrics_recording.mat`：逐包原始及归一化 I/Q 点、逐包指标表、扁平星座点表和采集元数据。逐包记录含 `modulation`；元数据含调制名称、阶数、完整参考星座、参考相位及 `normalization_divisor` 等幅度换算说明。
- `constellation_points.csv`：每个星座点的包号、包内点号、电脑接收时间、原始及归一化 I/Q，以及 `modulation` 列。
- `packet_metrics.csv`：逐包接收计数、CRC 计数、`rms`、EVM、MER、PER 和 BER 估算值，以及 `modulation` 列。
- `dashboard.png`：停止采集时的界面图像，包含调制选择和实时数值。

时间戳是 MATLAB 电脑处理 UDP 接收事件的时间；同一包中的星座点共用该时间，不是 FPGA 对每个采样点分别打的时间戳。CSV 时间保留到毫秒，MAT 保留接收时间的 datetime 值。即使停止时尚未收到数据，也会保存带列名的空表及当前调制的采集元数据。采集结果保留在本地，不纳入 Git。

## 验证状态

2026-11-04，MATLAB R2023b Update 6 下的 8 项离线回归全部通过，覆盖三种参考星座、已知幅度及相位误差下的 EVM/MER、切换清屏、采集及保存期间锁定、重复采集时 PER 重置、启动及保存失败后的控件恢复、正常及零数据保存、文件调制标签和接收时间，以及关闭时的资源清理。此前已验证 IP 偏好设置恢复；本轮回归保持本机偏好设置不变。

另对三种调制的历史 MAT 各取 10 包，共 15000 点做只读辅助检查，重算指标与独立的最近参考点计算一致，源文件 SHA-256 校验保持不变。历史文件的调制名称及原存指标不能单独证明当前默认幅度、相位已标定。`.27` 与 `.28` 板卡的调制支持、参考点匹配、实时曲线及保存结果仍待实验环境分别核对；本机回环、合成数据和历史数据检查不代替实板验收。

离线回归可在仓库目录运行，UDP 请求仅发往本机回环地址，输入数据由测试合成，保持当前电脑的 IP 偏好设置：

```matlab
results = runtests('tests/test_WPR_Metrics_GUI.m');
assertSuccess(results);
```

测试输出放在 Git 已忽略的 `过程文件/调制选择离线验收/`，与正式采集目录分开。实验室验收时需分别连接 `.27` 和 `.28`，核对每块板卡实际支持的调制、红色参考点与接收点的幅度及相位匹配，以及 STOP 后保存的调制标签、时间和指标；默认参数仅在对应实板核对后才可作为测量依据。
